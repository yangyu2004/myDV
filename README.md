# myDV (抖音 TV 版) - v1.0.5 经典版二开定制版

> **项目说明与声明**：  
> 本项目为 **myDV（抖音 TV 客户端）v1.0.5 经典版本的二次开发定制版本（二开）**。  
> 原项目地址：[mytv-android/myDV](https://github.com/mytv-android/myDV)（致敬原作者）。  
> 
> **二开背景**：  
> 官方在后续版本中进行了较大重构，但不少 TV/投影仪用户更偏爱 v1.0.5 极其纯净、轻量且直观的经典交互架构。然而原版 v1.0.5 存在菜单按键冲突、刷视频黑屏缓冲、喜欢接口失效、缺少收藏功能等痛点。本项目在完全保留 v1.0.5 经典界面与轻量架构的前提下，进行了深度逆向重构与功能补完。

---

## 🌟 二开核心定制特性

### 1. 抽屉导航按键彻底拦截（解决快进/快退冲突）
- **痛点**：原版按菜单键唤出顶部抽屉后，按左右键切换 Tab 时会透传给底层的短视频播放器，导致视频疯狂快进/快退。
- **改进**：重构底层 Activity `dispatchKeyEvent` 事件分发层。在抽屉展开时，`DPAD_LEFT` (21) 与 `DPAD_RIGHT` (22) 专职用于切换抽屉 Tab，并直接消费返回 `true`，**彻底杜绝事件透传至底层播放器**；按 `DOWN` (20)、`CENTER` (23) 或 `ENTER` (66) 确认选择并收回抽屉；按 `BACK` 仅关闭抽屉，交互逻辑符合大屏直觉。

### 2. 视频无缝预加载即切即播（消除黑屏缓冲）
- **痛点**：每次切视频都要等待短暂加载，体验卡顿。
- **改进**：在“设置”页中新增「**预加载设置**」选项：
  - 支持配置预加载数量：**1 / 3 / 5**（默认 3）。
  - 底层打通 Compose `VerticalPager` 超出可视边界渲染机制（`beyondBoundsPageCount`）与后台 ExoPlayer 预加载队列，提前对后续多条短视频进行流媒体握手与首帧预热，实现真正的**无缝即切即播**。

### 3. 修复个人中心“喜欢”功能
- **痛点**：原版喜欢列表加载异常或错调作品接口。
- **改进**：修复 ViewModel 模式路由参数，正确走官方喜欢列表接口 `/aweme/v1/web/aweme/favorite/`，并补全 User Profile 异步获取时序，点赞喜欢内容稳定呈现。

### 4. 新增短视频“收藏”网格与播放
- **痛点**：原版个人中心仅有作品和关注，电视端最常用的收藏夹缺失。
- **改进**：完整实现官方 Web 收藏接口 `/aweme/v1/web/aweme/listcollection/` 协议解析，增加分页游标（cursor）支持；在个人中心以短视频海报网格展示，遥控器点击任意项直接全屏开播。

### 5. 剔除“粉丝”标签
- **改进**：电视与投影仪场景下粉丝列表完全无实际价值，将原位置彻底移除，由“收藏”原位替换，界面整洁聚焦。

### 6. 防降级覆盖升级
- **改进**：二进制补丁 Manifest `versionCode="100"`，支持在电视设备上直接平滑覆盖安装，无需卸载原有应用。

## 📥 下载与安装

已编译且签名的稳定 APK 可直接在 Releases 中下载：

👉 **[前往 Releases 下载最新 APK (`myDV-v1.0.5-mod.apk`)](https://github.com/yangyu2004/myDV/releases)**

### 安装方式：
1. **U 盘安装**：下载 APK 存入 U 盘，插到电视/投影仪上通过文件管理器安装。
2. **ADB 远程安装**：
   ```bash
   adb connect <电视IP>:5555
   adb install -r myDV-v1.0.5-mod.apk
   ```

## 🛠️ 本地编译与构建

项目保留了完整的可逆向汇编源码与工程结构，任何开发者均可自行构建与修改：

### 环境依赖
- **Java Runtime**：JDK 17 或以上
- **Android SDK Build-Tools**（可选，脚本会自动检测系统路径中的 `zipalign` 与 `apksigner`）
- **Python 3**（用于构建 Manifest 补丁）

### 构建步骤
```bash
git clone https://github.com/yangyu2004/myDV.git
cd myDV

# 执行一键构建脚本（自动汇编 DEX、注入基础包、对齐并签名）
./scripts/build.sh
```
构建产物将输出至：`dist/myDV-v1.0.5-mod.apk`。
